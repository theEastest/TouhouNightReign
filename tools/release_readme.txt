TouHouNightReign — Windows x64 Release

启动游戏
1. 将 ZIP 完整解压到一个可写文件夹，例如 D:\Games\TouHouNightReign。
2. 双击 StartGame.bat 启动游戏。也可以双击同目录的 TouHouNightReign.exe。
3. 请保留整个文件夹的结构，不要只复制 EXE，也不要直接在压缩包里运行。

运行环境
适用平台：64 位 Windows 10 / Windows 11。
引擎、所需音频/图形 DLL、Lua 脚本、游戏资源和中文字体均已包含。
无需安装 Lua、Python、Visual Studio 或 CMake。

基本操作
方向键：移动 / 菜单选择
Z：射击
X：Bomb
左 Shift：低速移动
Enter / Space：确认菜单选项
Esc：返回 / 取消
地图也支持鼠标操作。

局域网
在主菜单选择创建或加入局域网服务器。加入时填写主机的局域网 IP，
双方使用相同端口（默认 27123）。首次联机如 Windows 防火墙提示，
允许游戏在所使用的专用网络通信。

存档与故障排查
每位玩家的存档和设置保存在本文件夹的 userdata 中，首次运行自动生成。
更新游戏前可以备份自己的 userdata；本发布包不包含开发者存档。
启动或运行异常时，请将本文件夹生成的 engine.log 发给开发者。

本包是当前开发中游戏的 Release 构建，游戏内容与稳定性仍会继续完善。
引擎及其依赖的授权说明保留在 licenses 文件夹中。
